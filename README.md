# 🐧 ペンギンテニスDX

スマホ対応のテニスゲーム。CPU、同じ端末での対戦、壁打ち、8チームトーナメント、オンラインの1対1・2対2・1対2・2対1を収録。

## GitHub Pages に公開する

1. このフォルダの **index.html / style.css / game.js / firebase-config.js** をGitHubリポジトリの一番上にアップロード。
2. GitHubの **Settings → Pages → Build and deployment → Deploy from a branch** で `main` / `(root)` を選択。
3. 表示された `https://ユーザー名.github.io/リポジトリ名/` にアクセス。

## オンライン対戦を有効にする（必須）

1. https://console.firebase.google.com/ でFirebaseプロジェクトを作成。
2. **Authentication → Sign-in method → Anonymous（匿名）** を有効化。
3. **Realtime Database** を作成。Realtime Database の「ルール」に `database.rules.json` の内容を貼って公開。
4. プロジェクトの設定で **ウェブアプリ** を登録。表示された設定値を `firebase-config.js` にコピー。`databaseURL` はRealtime DatabaseのURLを入力。
5. `firebase-config.js` をGitHubにアップロードし直す。
6. ゲームの「🌍 オンライン対戦」→「🏠 部屋を作る」。表示された6桁の番号を友だちに伝える。
7. 友だちは同じゲームURLを開いて部屋番号で参加。全員参加するとホストが開始できる。

**注意:** GitHub Pagesだけではオンライン通信はできません。Firebaseの初期設定が必要です。Firebaseの設定値は公開Webアプリ用の情報ですが、管理者用秘密鍵やサービスアカウント鍵は絶対にアップロードしないでください。ここに同梱したDBルールは試作用です。匿名ユーザーなら部屋番号を知っていればデータを読み取れるため、個人情報を入れないでください。部屋番号は秘密認証ではありません。公開規模を拡大する場合は、認可・不正操作対策・使用量制限を強化してください。

**現バージョンのオンライン仕様:** 参加者数が人数設定に達すると開始。ホスト端末がゲームの物理演算を担当し、Firebase Realtime Databaseで入力とゲーム状態を同期します。通信遅延や接続切れの際には不安定になる場合があります。オンラインのトーナメントは未対応で、トーナメントはローカルモードのみです。部屋のホストが切断すると部屋は終了します。

## 操作

矢印：移動。🎾うつ：ボールが近くに来たら打ち返す。🏐サーブ：サーブ。⚡：押しながら移動でダッシュ。🔥必殺：ゲージ100%で使う。⭐はゲージ増加、⚡アイテムはボール速度増加。

人数設定で操作パネルが自動的に変わります。1人操作なら横長、2人操作なら横並びのコンパクト表示です。
